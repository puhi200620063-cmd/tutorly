# Tutorly — единая спецификация продукта (версия 2.0)

## Позиционирование
Tutorly — цифровое рабочее пространство частного репетитора. Продукт помогает преподавателю организовать собственную практику: вести карточки учеников, планировать занятия, подбирать материалы, выдавать домашние работы и анализировать учебный прогресс.

## Роли и доступ
- Единственная роль в продукте: **Репетитор**.
- Ученик — объект учёта в рабочем пространстве репетитора, а не пользователь системы.
- У ученика нет регистрации, логина, пароля, кабинета, сессии или самостоятельного доступа к данным.
- Родительский кабинет и роль администратора в текущий объём не входят.
- Данные учеников доступны только владельцу соответствующего рабочего пространства.

## Основные модули
1. Главная: сводка по активным ученикам, занятиям, библиотеке и домашним работам; быстрые действия.
2. Ученики: создание, просмотр, редактирование, архивирование/удаление; класс, предмет, контакты, заметки, статус, история.
3. Библиотека заданий: математические задания на старте; поиск; фильтры по теме, классу, сложности; ответы для преподавателя.
4. Домашние работы: выбор ученика и задач, название, срок, статусы, результат; экспорт в PDF.
5. Календарь: занятия с датой, временем, длительностью, учеником и заметками.
6. Аналитика: сводка результатов, выполнение домашних работ, динамика по периодам и темам.
7. Тарифы: Free и Pro как продуктовые ограничения без реального платёжного шлюза.
8. Настройки: профиль преподавателя и параметры рабочего пространства.

## Тарифная гипотеза
- Free: до 3 учеников, базовая библиотека, PDF, календарь и базовая аналитика.
- Pro: 490 ₽/месяц как гипотеза из учебных материалов; расширенные лимиты, шаблоны и аналитика.
- Переключение тарифов в учебном прототипе демонстрационное. Оплата не подключена.

## Дизайн
- Тёмная технологичная тема.
- Основные цвета: глубокий navy (#090E1B / #101929), фиолетовый акцент (#8876FA), спокойные зелёные статусы.
- Шрифт Manrope для заголовков, DM Sans для текста.
- Адаптивность: desktop, tablet, mobile; мобильная навигация сворачивается.
- Состояния: hover, active, empty, success, error; понятные подписи и контраст.

## Техническая архитектура
- React + TypeScript/Vite frontend.
- FastAPI backend.
- PostgreSQL + SQLAlchemy; миграции Alembic должны быть добавлены до production.
- JWT access token и хеширование паролей.
- ReportLab для PDF.
- Docker Compose для локального запуска.

## Критерии приёмки
- В продукте нет входа или кабинета ученика.
- Все CRUD-операции проверяют владельца данных на сервере.
- Free ограничивает количество учеников тремя.
- PDF поддерживает кириллицу, переносы и корректную нумерацию.
- Календарь связывает событие с карточкой ученика.
- Аналитика рассчитывается из сохранённых результатов; при недостатке данных это явно показано.
- Интерфейс не ломается на ширинах 390, 768 и 1440 px.
- Все основные кнопки ведут к реальному действию; нет фиктивных обещаний о сохранении/оплате.
