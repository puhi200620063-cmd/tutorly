## ЧАСТЬ 2: Frontend на GitHub Pages (2 минуты)

### 1. Включите GitHub Pages

1. Откройте ваш репозиторий: **[github.com/puhi200620063-cmd/tutorly](https://github.com/puhi200620063-cmd/tutorly)**
2. Перейдите в **Settings** (вверху справа)
3. Слева найдите **"Pages"**
4. В разделе **"Source"** выберите:
   - Source: **GitHub Actions**
5. Сохраните

---

### 2. Дождитесь деплоя

1. Перейдите во вкладку **"Actions"** репозитория
2. Вы увидите workflow **"Deploy to GitHub Pages"** (запущен автоматически)
3. Подождите ~2 минуты, пока он завершится (зелёная галочка ✓)

---
