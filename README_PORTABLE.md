# 🚀 Tutorly - Портативная версия

## Что это?

Tutorly в виде папки с файлами. Скопируйте на любой компьютер и запустите одним кликом.

---

## ✅ Что нужно на компьютере преподавателя:

1. **Python 3.10+** → [скачать с python.org](https://www.python.org/downloads/)
2. **Node.js 18+** → [скачать с nodejs.org](https://nodejs.org/)

---

## 📦 Как использовать:

### Вариант 1: Перенос на флешке

1. Скопируйте **всю папку Tutorly** на флешку
2. На другом компьютере скопируйте папку с флешки
3. Двойной клик на **`START.bat`**
4. Браузер откроется автоматически!

### Вариант 2: Архив для отправки

1. Заархивируйте папку Tutorly в .zip
2. Отправьте по email / облаку
3. Получатель распаковывает
4. Двойной клик на **`START.bat`**

---

## 🎯 Что делает START.bat:

1. Проверяет Python и Node.js
2. Устанавливает зависимости (если нужно)
3. Запускает backend API
4. Запускает frontend
5. Открывает браузер с сайтом

**Всё автоматически!**

---

## 📋 Инструкция для преподавателя:

### Первый запуск (2-3 минуты):

1. Распакуйте архив/скопируйте папку
2. Двойной клик на **START.bat**
3. Подождите установку зависимостей
4. Браузер откроется автоматически
5. Зарегистрируйтесь и работайте!

### Следующие запуски (5 секунд):

1. Двойной клик на **START.bat**
2. Готово!

---

## 💾 База данных

**По умолчанию:** SQLite (файл `backend/tutorly.db`) — работает без интернета

**Опционально:** Можно использовать Neon PostgreSQL:
- Переименуйте `.env.local` (если есть) или создайте
- Добавьте `DATABASE_URL=postgresql://...`

---

## 🛑 Остановка

Закройте окно командной строки или нажмите **Ctrl+C**

---

## ❓ Решение проблем

**"Python не найден":**
- Установите Python с python.org
- При установке отметьте "Add Python to PATH"

**"Node.js не найден":**
- Установите Node.js с nodejs.org

**Порты заняты:**
- Закройте другие программы на портах 8000 и 5173
